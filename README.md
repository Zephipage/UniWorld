# UniWorld

Project page for **UniWorld: A Unified World Model for Real-Time Visual World Simulation**.

- [Project website](https://zephipage.github.io/UniWorld/)
- [Paper on arXiv](https://arxiv.org/abs/2610.32381)

Xin Zhang, Yabo Chen, Shuaiwei Wang, Zixuan Duan, Haibin Huang, Feng Xu, and Xuelong Li.

## Preview

Run `python -m http.server 8000` in this directory and visit `http://localhost:8000/`.

The site is static HTML, CSS, and JavaScript with local figures, fonts, videos, and PDF assets. GitHub Pages serves the `main` branch from the repository root. No build step is required.
